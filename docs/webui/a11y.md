# 可访问性（A11y）

linling-webui 面向 WCAG 2.1 AA，以下是承诺与已知局限。

## 承诺

### 1. Reduced motion
`prefers-reduced-motion: reduce` 下：
- 所有 CSS 动画压到 0.001ms
- `DecoPetalCanvas` / `DecoBreezeLayer` / `DecoBellAccent` 整体 `display: none`
- 铃铛音效、震感也会静默

### 2. 键盘导航
- Tab 顺序跟随 DOM，移动 shell 不使用 tabindex 陷阱
- `Esc` 关闭 `UiSheet` bottom-sheet
- `Enter` 提交主表单（登录、试聊）
- `/`（未实装页级搜索聚焦，`useKeyboardShortcuts` composable 预留）

### 3. 语义
- 所有装饰层 `aria-hidden="true"`
- 流式 agent bubble 容器 `aria-live="polite"`
- Toast 栈 `aria-live="polite" role="status"`
- Landmark：`<header> <main> <nav> <footer>`，均来自 `AppShell.vue`

### 4. 触达尺寸
所有 tappable 元素 `min-height: 44px`、`min-width: 44px`（`.tap` utility）。
`Playwright e2e` 任务 38.3 对每页扫描 bounding box（待执行）。

### 5. 对比度
见 `docs/webui/theme.md`。主要文字组合均 ≥ 4.5:1，大多数 > 11:1。
axe-playwright 扫描（任务 34.2）待接入。

### 6. 表单
- `<label>` 关联 `<input>` 通过嵌套
- 错误态通过 `aria-live` 文本 + 颜色双通道传达（不只靠颜色）
- autocomplete 按语义填（`username` / `current-password`）

## 已知局限 · TODO

- 还未做屏幕阅读器全面测试（NVDA / VoiceOver）
- `UiVirtualList` 对 keyboard navigation 的支持是 best-effort，长列表翻页仍依赖鼠标滚动
- Monaco JSON 编辑器懒加载尚未安装（Kv 当前用 textarea，对 SR 友好但语法高亮缺失）
- 高对比度 Windows 模式未单独调色盘
